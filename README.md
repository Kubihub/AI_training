# Youth in AI × Proficio: Data Science & AI Training

Training materials for the Youth in AI × Proficio Global Impact Foundation Data Science & AI programme for senior high school and university students in Ghana.

## What's here

| File | What it is |
| --- | --- |
| `index.html` | Front page for GitHub Pages; forwards visitors to the hub. |
| `data-ai-learning-hub.html` | The Learning Hub: 6 phases and 20 modules, each with a lesson, practice task, quiz and resources. Trainers can download each phase as a PowerPoint deck from inside the app. |
| `Learning-Hub-Guide.pdf` | 8-page guide for trainers and learners: using the hub, what to install for each phase, age rules for AI tools, and a trainer checklist. |
| `test_gemini.py` | Pre-cohort check that the Gemini code examples still run. Needs your own key in the `GEMINI_API_KEY` environment variable (18 and over only). |
| `Data and AI Training (2).pdf` | The original curriculum outline. |
| `Pedagogical Support Framework (2).pdf` | The facilitator support framework. |
| `Copy of YIAI icon 1 light.png` | The Youth in AI wordmark. |

## Using the Learning Hub

**Online:** https://kubihub.github.io/AI_training/ (GitHub Pages, public).

**On your computer:** open `data-ai-learning-hub.html` in Chrome, Edge, Firefox or Safari. It needs an internet connection the first time it opens.

Keep `Learning-Hub-Guide.pdf` in the same folder as the HTML file: the hub's guide button looks for it there.


## Slide decks

The `slides/` folder is not stored in this repository. Regenerate the decks with the **Download Phase N slides** buttons in the hub.

## Keep out of this repository

- API keys and passwords
- Learner data: class lists, ages, scores, phone numbers (Ghana's Data Protection Act, 2012, Act 843)
- Copies of the guide with the contacts table filled in

`.gitignore` already blocks the common cases.
